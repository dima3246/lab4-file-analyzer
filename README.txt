Лабораторная 4. Вариант 1 — анализатор файловой системы.
Python 3.10+, стандартная библиотека. Запуск:
python analyzer.py
python analyzer.py sample --output report.txt
python verify.py
Без аргумента программа спрашивает каталог.
МБ десятичные: 1 000 000 байт. Ссылки пропускаются, расширения
приводятся к нижнему регистру, сам report.txt исключается из подсчёта.
verify.py создаёт собственный sample и проверяет одинаковые данные на двух ОС.
Для снимков отчёта запуска в CI используется Playwright; анализатору он не нужен.
Снимки показывают настоящий stdout и report.txt в браузере соответствующего runner.
